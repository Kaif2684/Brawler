
# BRAWLER - A 2D Fighting Game

BRAWLER is a 2D fighting game built using Python and Pygame. It features two fighters, a **Warrior** and a **Wizard**, who battle it out in an intense one-on-one duel. The game includes animations, sound effects, and health bars for an engaging experience.

## 🎮 Features

- **Two Playable Fighters:** Warrior and Wizard, each with unique animations and abilities.
- **Smooth Animations:** Character movements and attacks are animated using sprite sheets.
- **Health Bar System:** Displays remaining health for both players.
- **Sound Effects & Music:** Background music and attack sounds for an immersive experience.
- **Victory Screen:** Displays a win message when a player is defeated.
- **Countdown Timer:** Before each round, a countdown timer appears.

## 🛠️ Installation & Setup

1. **Clone the Repository:**
   git clone https://github.com/Kaif2684/Brawler.git
   cd Brawler

2. **Install Dependencies:**
   pip install pygame

3. **Run the Game:**
   ```sh
   python main.py
   ```

## 📜 Game Mechanics

- Both fighters start with **100 health points**.
- Players can **move left, right, jump, and attack**.
- If a player's health reaches **0**, the opponent wins the round.
- After a short cooldown, the next round begins.
